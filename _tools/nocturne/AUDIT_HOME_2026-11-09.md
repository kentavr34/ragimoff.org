## Корневые причины (почему «половины элементов не видно»)

1. **Анимации выключены системой.** На ПК Кенана в Windows отключена анимация → `prefers-reduced-motion: reduce` →
   скрипт сайта гасит ВСЁ: появление блоков (на странице 0 анимированных элементов), наведение, свет. Отсюда «сухой текст».
   Исправление: уважать настройку только для резких движений (параллакс, полёты), а мягкие появления (прозрачность,
   сдвиг ≤ 12 px, раскрытие маской) оставить; табличку «анимации отключены» убрать.
2. **Блоки старого сайта перенесены почти как есть** (программы, экосистема, «о специалисте», книги, услуги, блог, подвал) —
   новый только цвет. Стандарт карточек 08.11 решал отступы, но не выравнивание строк между карточками.
3. **Из 100 приёмов референса на главной работают 3** (скраб кадров, бегущая строка, зерно). Нет: горизонтальной галереи
   на вертикальном скролле, стопки карточек, пословного/построчного проявления текста, раскрытия изображений, магнитных
   кнопок и hover с перекатом текста, раскрывающегося словесного знака в подвале, редакционного подвала.

## Стандарт (дополнение к DESIGN-STANDARD §9)

- **Выравнивание строк между карточками одного ряда.** Каждый тип элемента карточки (метка, название, описание, строки,
  итог, кнопки) стоит на одной горизонтали во всех карточках ряда: CSS `grid-template-rows: subgrid`. Карточки ряда
  одной высоты; отступ под кнопкой = отступу сверху.
- **Названия карточек** — в одну строку: кегль подбирается по самому длинному названию ряда.
- **Подзаголовок секции** — одна строка; если не помещается — две равные строки по словам.
- **Все блоки** — в общей сетке `n-wrap` (поле 93 px при 1440).
- **Движение** — у каждого блока есть вход (проявление) и реакция на наведение. Системная настройка «без анимации»
  гасит только резкие движения.

## Порядок работ

1. Первый экран: 90 чётких кадров, короче прокрутка.
2. Движение: мягкий режим вместо полного отключения; убрать табличку.
3. Программы: без PDF, подсетка, отдельная карточка Психодиагностики, горизонтальный скролл / стопка.
4. Экосистема, услуги: подсетка, равные высоты, подзаголовки.
5. О специалисте: таймлайн с проявлением, лента сертификатов; личная страница без повтора фото.
6. Книги в сетку. 7. Блог — лента. 8. Подвал — 4 колонки + словесный знак. 9. Шкала шрифтов, кнопки.
10. Проверка: замер выравнивания (одна линия ±2 px), десктоп + телефон, `verify.py`.
