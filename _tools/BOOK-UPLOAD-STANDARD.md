## 2. Что уже ломалось (не повторять)

1. **`\b` в JS не работает с кириллицей и азербайджанскими буквами** (İ, Ə, Ş, Ğ, Ö, Ü, Ç) —
   границу слова задавать явным классом `(?![A-Za-zА-Яа-яƏəİıÖöÜüÇçŞşĞğ])`.
2. **`«İ».toUpperCase()`/`/i` не отождествляют İ и i** — в правилах для AZ перечислять варианты
   (`ci|cİ|cI|cı|cu|cU|cü|cÜ`) или задавать буквы классами (`[iİıI]`).
3. **Строка, оканчивающаяся цифрой, считалась строкой оглавления** — «голые» маркеры (`ГЛАВА 1`)
   вылетали из тела. Фильтр оглавления обязан пропускать их.
4. **Абзацы внутри таблиц** (`<w:tbl>`) — не заголовки: в книгах в таблицах встречаются
   «ВВЕДЕНИЕ», «РАЗДЕЛ 2», «GİRİŞ» — иначе появляются ложные главы.
5. **Вводные разделы — только в начале книги** (`ВВЕДЕНИЕ`/`GİRİŞ` посреди текста главой не делать).
6. **В название главы дописывать только строки-заголовки** (жирные, с размером) и не вливать
   буквенные подпункты (`A. Elmi mənbələr`) — иначе «· PRİNSİP · MƏZMUN» и подобный мусор.
7. **Крупный подзаголовок после «Bölüm N. MÜNASİBƏT MODELİ»** — часть названия, а не новая глава.
8. **Опечатки источника** («bÖLÜM», «FƏSİL 12» вместо «Bölüm 12») нормализовать в конвертере,
   а не править книгу.
9. **Оглавление сайта = оглавление книги**: части, главы, подпункты, без номеров страниц.
   Сопоставление — по маркеру+номеру, имени в «…», первому/последнему слову; İ и ı приводить к i.
10. **Ссылки:** на индекс книги — `index.html` своего языка; «← ragimoff.org» оставлять и вести
    по языку страницы (AZ → корень, RU → /ru/); переключатель языка — только языки книги
    (`data-langs`), адреса объявлять в `data-lang-url-*` (слаги глав в языках разные).
11. **Служебные страницы книги** (тест и т.п.): `padding-top: calc(var(--hdr) + 30px)` — шапка
    закреплена; свои отступы задавать селектором не слабее `.content-wrap <класс>`
    (`.content-wrap p` из каркаса специфичнее).
12. **Кнопки — только в стиле сайта** (`.kitab-btn`: заливка `--gold`, тёмный текст, радиус 8).
    Классы, которых нет в `style.css`, не выдумывать.

## 4. СТИЛИСТИЧЕСКИЕ ТРЕБОВАНИЯ К ОГЛАВЛЕНИЮ И ПОДАЧЕ ТЕКСТА (Кенан, 29.09.2026)

Записано по разбору книг Фрейда. **Каждый пункт — из замечания владельца, повторять не спрашивая.**

### 4.1. Оглавление берётся у ТОГО, КТО ПЕЧАТАЛ КНИГУ

- В печатном издании есть страница оглавления. **Её и брать за образец** — те, кто верстал книгу,
  думали о структуре. Не выдумывать своё, не портить качество.
- Если в печатном оглавлении есть **подглавы и подпункты** — переносить их на сайт тоже.
  Оглавление сайта = оглавление книги: части, главы, подпункты. Номеров страниц не переносим.
- **«Слишком мало глав» — это почти всегда глуповатый разделитель, а не короткая книга.**
  Проверять по печатному оглавлению: у «Толкования сновидений» 7 глав на 1,1 млн знаков — значит
  главы надо делить по подразделам печатного издания, а не отдавать по 160 тыс. знаков одной страницей.
- Оглавление **только из римских цифр (I, II, III) — недопустимо.** Если у произведения главы без
  авторских названий (так у «Недовольства культурой»), дать каждой главе осмысленное название
  по её содержанию — кратко и по-академически, либо взять названия из печатного оглавления издания,
  где они есть.

### 4.2. Имя автора — ПОЛНОСТЬЮ

- Везде: **`Ziqmund Freyd`** / **`Зигмунд Фрейд`** / **`Sigmund Freud`**.
- Сокращения вида **`З. Фрейд`, `Z. Freyd`, `Z. Froudun` — запрещены** (встречаются в оглавлениях
  и подписях; вычищать).
- То же для имён в тексте: имя целиком при первом упоминании, инициалы только внутри ссылок на литературу.

### 4.3. Письма — академический каталог, а не свалка

- Письмо — **отдельная страница** в разделе «Письма», внутри адресата строгая хронология.
- Заголовок письма = **`ДАТА — ТЕМА`**; дата в формате `ДД месяц ГГГГ` (неточная — в скобках).
- Если источник даёт **место написания и событие/повод** — указывать их (строка под заголовком).
- Пометки переводчика и издателя — в отдельный блок «Примечания», не в тело письма.

### 4.4. Афоризмы — с разделением и, где есть, с контекстом

- Каждый афоризм **отделён от соседнего** (отбивка), а не сплошная простыня.
- **Дата, место и событие произнесения** — если эти сведения есть в источнике, их указывать.
  Нет сведений — так и оставить, но **не выдумывать** (правило владельца: «где атрибуции нет — не выдумывать»).
- Если афоризмы идут группами (по темам или по произведениям-источникам) — группы озаглавить.
- Один корпус = одна книга, но внутри — структура, а не монолит.

### 4.5. Порядок проверки перед заявлением «готово» (дополнение к §3)

- [ ] оглавление сверено с печатным изданием (число глав И подглав);
- [ ] нигде нет сокращённого имени автора;
- [ ] ни одна книга не состоит из одной главы, если в печатном издании глав больше;
- [ ] у глав есть осмысленные названия (не только римские цифры);
- [ ] афоризмы и письма разделены и, где возможно, снабжены датой и местом.
