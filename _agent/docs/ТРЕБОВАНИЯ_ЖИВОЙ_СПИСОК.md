# ТРЕБОВАНИЯ ВЛАДЕЛЬЦА — ЖИВОЙ КОНТРОЛЬНЫЙ СПИСОК (test/11)

Правило: владелец не повторяет дважды. Каждое его замечание попадает сюда в тот же час и остаётся навсегда.
Перед показом любой страницы критик проверяет её по КАЖДОМУ пункту. Исторический свод (88 реплик) —
`test/69/_agent/docs/TREBOVANIYA_SVOD_11.11.2026.md`; он действует целиком, ниже — выжимка и новое за 11.11.2026.

## А. Смысл главной
1. Сначала эмоциональное доверие (движение, лица, красота, аккуратность), потом услуги. Доказать, что специалист — лучший.
2. Не спрашивать «что вам нужно» на входе. Двери — это сами блоки и кнопки героя.
3. Порядок: герой → специалисты → книги → обучение (7 программ) → консультации → тренинги → просвещение (мифы) → блог → Telegram.
4. Без самохвальства словами — только факты, документы, цифры.

## Б. Герой
5. Motion: женщина в костюме подходит, касается — появляется Doctor Ragimoff / Школа психологии.
6. Над головой героини — воздух: голова не касается меню и не заходит под него.
7. «Doctor Ragimoff» — в ОДНУ строку. Имя не кричит и не лежит на лице.
8. Никаких прямых полос по краям кадра. Затемнение — минимальное и плавное, только на переходе.
9. Текста в герое мало. Кадры резкие, без размытых лиц.
10. Четыре кнопки: Консультации, Обучение, Книги, Тренинги.

## В. Меню
11. Пункты: Специалисты, Книги, Обучение, Консультации, Тренинги, Блог, Контакты. «Просвещение» в меню НЕ нужно.
12. Ничего не выходит за край экрана («Записаться» в том числе) на любой ширине.
13. У заголовков — подзаголовки (все программы, темы, правовые основы); на телефоне раскрываются по стрелке.
14. Шапка уходит при прокрутке вниз, возвращается при движении вверх, не дёргается.
15. Слово «бизнес» не нравится — «Тренинги».

## Г. Единая система (главное)
16. Меняю шрифт в одном месте — меняется на всех страницах. То же цвет, отступы, анимации, темы.
17. Математика заголовка: отступ до и после заголовка = размеру его шрифта; заголовок → подзаголовок = половина размера.
18. Текст не прилипает к кнопке, кнопка — к блоку; соседние блоки не слипаются; проверять на ВСЕХ страницах.
19. Заголовок ≤ 2 строк, подзаголовок ≤ 2 строк, между ними воздух. Длинный текст — по левому краю, не «улей».
20. Ряды карточек симметричны, равной высоты, кнопки на одной линии.
21. Три темы, переключатель виден; три языка.

## Д. Содержание
22. Специалисты: фото + 3 строки статуса. Ни одного пикселя и ни одной буквы «не того» шрифта.
23. Книги: обложка, название, 3 строки «почему именно эта книга», кнопка «Читать» → сразу в читалку.
24. Обложка «Клинической психиатрии» на сайте — новая, сгенерированная; буква Ə не превращается в квадрат. Проверять все обложки на квадраты.
25. После книг: Фрейд впервые на азербайджанском, «Общая психотерапия» на подходе, пополнение в 2027.
26. Названия разделов — это названия («Обучение»), не описания. Жёлтых ярлыков не выдумывать.
27. Азербайджанский — проверять переводом. «Драма Сабины» = «Səbinənin draması».
28. Не придумывать факты и цены. Формы: консультация — имя, фамилия, телефон; обучение — + удостоверение, диплом по желанию.
29. Фотогалереи: подпись под каждой фотографией соответствует именно этой фотографии; галерея открывается по нажатию. Сверять глазами.

## Е. Как работать
30. Работать самостоятельно: искать лучшее решение в мире для каждой задачи и применять его.
31. Использовать свои ресурсы (опись: память `media-tools-and-mcp`): DashScope/Alibaba, ElevenLabs, Higgsfield, DeepInfra, NVIDIA — не спрашивать о том, что уже настроено.
32. Обязательный критик: независимые агенты-критики (дизайн, вёрстка, тексты) проверяют работу до показа владельцу; правки — по их замечаниям, цикл до чистого результата.
33. Цель: пересобрать ВЕСЬ текущий сайт по новой технологии в идеальной версии, без того чтобы владелец бегал по каждой странице.
34. Показ — только по ссылке на сайте; «готово» — только после проверки в браузере.
