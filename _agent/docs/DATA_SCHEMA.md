# test/11 — данные внутренних страниц (один формат на все страницы)

Каждая страница на каждом языке — один файл `test/11/data/<kind>/<slug>.<lang>.json` (`lang` = `ru` | `az` | `en`).
Страницу рисует один движок (`assets/js/blocks.js`) из списка блоков. Оформления в данных нет — только текст и адреса.

## Главное правило

Текст переносится с исходной страницы ДОСЛОВНО: ни слова не добавлять, не сокращать, не пересказывать, не переводить,
не исправлять. Каждая строка текста в JSON должна находиться в исходной странице — это проверяет
`python test/11/_tools/verify_data.py <файл.json>` (должно быть `0 расхождений`).
Структура блоков одной страницы на трёх языках одинакова (те же блоки в том же порядке, то же число пунктов),
если исходные страницы совпадают по составу. Если на каком-то языке раздела нет — блока нет, это нормально.

## Корень файла

```json
{
  "slug": "depressiya", "lang": "ru", "src": "ru/konsultasiya/depressiya.html",
  "eye": "Клиническая терапия",
  "title": "Лечение депрессии",
  "lead": "Клиническая, сезонная и послеродовая депрессия — …",
  "img": "/images/hero-n/depressiya.webp",
  "blocks": [ … ]
}
```
`src` — путь исходной страницы от корня сайта. `eye` — надстрочник над H1 (как на странице, обычным регистром букв:
«Клиническая терапия», а не «КЛИНИЧЕСКАЯ ТЕРАПИЯ», если капслок на странице сделан стилем; если в самом тексте — оставить).
`title` — H1 одной строкой (части через пробел). `img` — картинка героя, путь от корня сайта (`/images/…`), либо `null`.

## Блоки

У любого блока могут быть `h` (заголовок раздела, одной строкой) и `sub` (подзаголовок). Надстрочники разделов
(«СИМПТОМЫ», «ПРОЦЕСС ЛЕЧЕНИЯ») НЕ переносятся. Порядок блоков — как разделы на исходной странице.

| type | поля | для чего |
|---|---|---|
| `cards` | `num` (true — карточки с номерами), `items: [{t, d}]` | признаки, шаги, преимущества: заголовок + абзац |
| `groups` | `items: [{t, d, list: [строки], meta}]` | карточка со списком внутри (направления, модули) |
| `timeline` | `items: [{y, t, d, a: [подпись, адрес]}]` | путь по годам; `a` — если есть ссылка |
| `gallery` | `items: [{src, cap}]` | дипломы, сертификаты, фотографии |
| `videos` | `channel: [подпись, адрес]`, `items: [{yt, t, d}]` | ролики YouTube; `yt` — код ролика (11 знаков) |
| `who` | `label`, `ids: ["kenan" \| "samira"]` | «Ведёт консультации» — карточка специалиста |
| `prices` | `set: "consult" \| "enurez"` ИЛИ `rows: [[что, цена]]`, `note` | стоимость. Для консультаций ТОЛЬКО `set` — числа не переписывать |
| `articles` | `items: ["depressiya", "depressiya-2", …]` | список статей блога — только имена файлов без `.html` |
| `faq` | `items: [[вопрос, ответ]]` | вопросы и ответы |
| `list` | `items: [строки]` | маркированный список |
| `text` | `p: [абзацы]` | обычный текст |
| `stats` | `items: [[число, подпись]]` | полоса цифр |
| `table` | `caption`, `head: […]`, `rows: [[…]]` | таблица |
| `quotes` | `items: [{text, name, meta}]` | отзывы |
| `contact` | `items: [{t, p: [строки], btns: [[подпись, адрес]], note}]` | адрес, запись, почта |
| `links` | `items: [[подпись, адрес, пояснение]]` | список ссылок на документы |
| `note` | `t`, `d` | выделенное замечание |
| `figure` | `src`, `cap` | одна картинка с подписью |
| `cta` | `btns: [[подпись, адрес]]` | призыв с кнопками (WhatsApp и т. п.) |

Если раздел не ложится ни в один тип — взять ближайший (`cards`, `text`, `list`) и написать об этом в отчёте.

## Что НЕ переносится

Шапка, меню, «хлебные крошки», подвал, формы записи и калькуляторы (форма на новом сайте одна, общая),
плавающая кнопка WhatsApp, окно «Заказ книги», скрытые окна, надстрочники разделов.
Раздел «Стоимость консультации» с ценами за сессию и пакет → `{"type": "prices", "h": …, "sub": …, "set": "consult"}`
(цены на новом сайте берутся из одного места и только в манатах). Если на странице свои, особые цены
(не «сессия онлайн/очно» и «пакет») — перенести как `rows` дословно и ОБЯЗАТЕЛЬНО написать об этом в отчёте.

## Внутри строк

Разрешены только `<strong>`, `<em>`, `<a href="…">`, `<br>`, `<sup>`, `<sub>` — если они есть в исходном тексте.
Адреса ссылок и картинок: внутренние — от корня сайта (`/ru/konsultasiya/depressiya.html`, `/images/…`),
внешние — как есть. Движок сам переводит старые адреса в новые.
Неразрывные пробелы и типографские кавычки сохранять как в источнике. `&nbsp;` записывать символом U+00A0.
