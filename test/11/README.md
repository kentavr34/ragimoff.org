## Главная: что принято от владельца 11.11.2026

Главная сначала вызывает доверие (движение, лица, красота, доказательства компетенции), услуги — потом.
Двери — это сами блоки и кнопки героя, а не символы. Порядок: герой (девушка кликает → Doctor Ragimoff, Школа психологии,
четыре кнопки) → специалисты (фото + 3 строки) → книги (обложка + 3 строки превосходства + «Читать») → семь программ →
консультации → тренинги → просвещение (мифы → главы учебника) → блог → Telegram. Меню с подзаголовками, на телефоне — по стрелке.
