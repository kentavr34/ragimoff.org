1. Tərif və nozologiya

Postnatal Psixoz (PPP; XBT-11: 6E21; DSM-5-TR: peripartum başlanğıc kvalifikatoru ilə qısamüddətli psixotik pozuntu və ya bipolyar I pozuntu) — doğuşdan sonra (tipik ilk 2 həftə) kəskin başlanğıclı psixotik epizod; hallüsinasiyalar, sayıqlamalar, koqnitiv dezorqanizasiya, əhval dəyişkənliyi. Tibbi təcili haldır — körpə qətli (infantisid) riski təxminən 4%, ananın intihar riski isə yüksəkdir.

2. Tarixçə

  • Marcé L.V. (1858) — postnatal psixozun klassik təsviri.
  • Bergink V. və b. (2015) — 4-pilləli müalicə alqoritmi.
  • NICE CG192 — doğuş ətrafı dövrdə psixiatrik vəziyyətlərə dair təlimat.

3. Epidemiologiya

  • İnsidens (xəstələnmə tezliyi): hər 1000 doğuşa 1–2 hal düşür.
  • Bipolyar pozuntu tarixçəsi olan qadınlarda 25–50%; əvvəlki PPP tarixçəsi olanlarda residiv riski 30–40% (profilaktikasız 44%-ə qədər).
  • Komorbidlik: əksər hallarda əsas diaqnoz bipolyar pozuntudur.
  • Mortalitet: infantisid 4%, intihar 5%-ə qədər (müalicəsiz).

4. Etiologiya və patogenez

  • Hormonal amil — doğuşdan sonra estrogen və progesteron səviyyəsinin kəskin enməsi müşahidə olunur.
  • Yuxu məhrumiyyəti.
  • Bipolyar pozuntu meyilliliyi (əksər PPP — bipolyar epizod təzahürü).
  • Ailə tarixçəsi.

5. Klinik təzahürlər

  • Sürətli başlanğıc (24–72 saat, tipik ilk 2 həftə).
  • Polimorf psixotik simptomlar — sayıqlamalar (xüsusilə körpə haqqında — körpənin «şeytan» və ya «seçilmiş» olması; ana «qurtarmalı»), hallüsinasiyalar.
  • Əhval dəyişkənliyi — manik və ya depressiv komponentlər.
  • Koqnitiv dezorqanizasiya, qarışıqlıq.
  • Yuxu pozulması ağırdır.
  • Davranış — qəribə (bizar), həddindən artıq, körpə baxımının pozulması.
  • Yüksək risk: ana intihar, körpəyə zərər (infantisid).

6. Diaqnoz

6.1 Vahid diaqnostik meyarlar

Klinik diaqnoz: doğuşdan sonra kəskin başlanğıclı psixotik epizod; bipolyar manik və ya kəskin psixotik kateqoriyasında kodlanır; peripartum başlanğıc göstəricisi əlavə edilir.

6.2 Mənbələr arasında fərqlər

  • NICE CG192 — təcili tibbi vəziyyət.
  • RCPsych (ing. Kral Psixiatrlar Kolleci) — perinatal psixiatrik xidmət standartları.

6.3 Diaqnostika alqoritmi

  1. Klinik müsahibə — sürətli başlanğıc, simptom təbiəti.
  2. Tibbi qiymətləndirmə — doğuşdan sonrakı dövrün tibbi səbəbləri (tiroidit, infeksiya, ensefalopatiya, eklampsiya, B12 çatışmazlığı) istisna.
  3. Laborator — TSH, tam qan, elektrolitlər, qaraciyər, böyrək, ammonyak, qlükoza, infeksiya markerləri.
  4. Beyin MRT və EEQ — atipik təqdimat və ya neyroloji əlamətlər varsa (autoimmun ensefalit — anti-NMDA-R xüsusilə!).
  5. Toksikoloji müayinə.
  6. İntihar və infantisid riskinin qiymətləndirilməsi (Kolumbiya İntihar Şiddəti Şkalası (C-SSRS); körpənin təhlükəsizliyi).

6.4 Differensial diaqnostika

Vəziyyət Fərqləndirici əlamətlər
Postnatal depressiya (6E20) Psixotik simptom yoxdur.
Postnatal OKP Eqo-distonik intruzivlər; xəstəlik şüuru saxlanılır.
Delirium (6D70) Diqqət dalğalanması; tibbi səbəb (infeksiya).
Anti-NMDA-R ensefalit Atipik psixoz, hərəki simptomlar və tutmalar; BOM antikorları; klassik təzahür gənc qadınlarda müşahidə olunur.
Eklampsiya/HELLP Hipertenziya, qıcolmalar, hemoliz, trombositopeniya.
Sheehan sindromu Hipopituitarizm (doğuşdan sonrakı kütləvi qanaxma nəticəsində).

7. Müayinə və qiymətləndirmə

  • Klinik psixiatrik və neyroloji.
  • Yuxarıdakı tibbi panel.
  • Anti-NMDA-R antikorlar (CSF) — atipik halda.
  • C-SSRS, körpə təhlükəsizliyi.

8. Müalicə

8.1 Ümumi prinsiplər (NICE CG192, Bergink 2015)

  1. Təcili hospitalizasiya mütləqdir — ana və körpə üçün; mümkünsə ana-körpə bölməsində (Mother-Baby Unit, MBU).
  2. Bergink 4-pilləli alqoritm (Am J Psychiatry 2015):
    • Pillə 1: Benzodiazepin (lorazepam) kəskin stabilizasiya;
    • Pillə 2: Atipik antipsixotik (olanzapin, kvetiapin, risperidon);
    • Pillə 3: litiumun əlavə edilməsi;
    • Pillə 4: EKT refrakter və ya katatonik xüsusiyyətlərdə.
  3. Bipolyar əsas əksər halda — litium birinci sıra. Valproat uşaq doğa bilən (reproduktiv yaşda olan) qadınlarda əks-göstərişdir və yalnız Hamiləliyin Qarşısının Alınması Proqramının şərtləri yerinə yetirildikdə və effektiv kontrasepsiya təmin edildikdə istifadə oluna bilər; hamiləlik dövründə isə əks-göstərişdir (EMA/MHRA 2018).
  4. Əmizdirmə qərarı — litium əmizdirmədə nisbi əks-göstərişdir (südə keçən); olanzapin və kvetiapin nisbətən təhlükəsiz; pasiyent və ailə ilə müzakirə.
  5. Sonrakı hamiləliklərdə residiv riski yüksək (təxminən 30–40%) — profilaktik litium doğuşdan əvvəl və sonrakı dövrdə tövsiyə olunur.
  6. EKT hamiləlikdə və doğuşdan sonrakı dövrdə təhlükəsizdir; effekti sürətlidir.
  7. Multidisiplinar koordinasiya — psixiatr, mama-ginekoloq, pediatr, sosial işçi.

8.2 Müalicə metodikaları

  1. Berginkin dörd pilləli alqoritmi (Bergink) — Benzodiazepin → antipsixotik → litium → EKT.
  2. Ana-Körpə Bölməsi (MBU — Mother-Baby Unit) — Ana və körpənin birgə hospitalizasiyası; bağlanmanın (bonding) qorunması və təhlükəsizlik.
  3. EKT doğuşdan sonrakı dövrdə — hamiləlikdə və əmizdirmədə təhlükəsizdir; sürətli effekt; katatonik xüsusiyyətlərdə birinci sıra.
  4. Profilaktik Litium Sonrakı Hamiləliklərdə — Bergink V. və b. Am J Psychiatry 2012 — peri-postpartum dövründə residiv profilaktikası.

8.3 Mənbələr arasında fərqlər

  • NICE CG192 — Ana-Körpə Bölməsi (ing. Mother-Baby Unit) tövsiyəsi.
  • Bergink V. və b. Am J Psychiatry 2015 — 4-pilləli alqoritm sübut bazası.

9. Proqnoz

  • Adekvat müalicə ilə pasiyentlərin əksəriyyətində tam bərpa müşahidə olunur.
  • Sonrakı hamiləliklərdə residiv yüksək (təxminən 30–40%).
  • Bipolyar pozuntunun uzunmüddətli idarə edilməsi vacibdir.

10. Miflər və yanlış inanclar

Mif 1: «PPP „ana hisslərinin“ güclü ifadəsidir»

Sübut: klinik psixotik vəziyyət; infantisid və intihar riski yüksəkdir; təcili müdaxilə.

Mif 2: «Ev şəraitində izləmək kifayətdir»

Sübut: NICE CG192 — xəstəxanaya yerləşdirmə mütləqdir; ana-körpə bölməsi (MBU) üstünlük təşkil edir.

Mif 3: «Əmizdirmə üçün antipsixotik və litium qadağandır»

Sübut: olanzapin və kvetiapin əmizdirmədə nisbətən təhlükəsiz; litium süd-keçər, lakin uşaq monitorinqi ilə tövsiyə oluna bilər; fərdi balans.

Mif 4: «Sonrakı hamiləlikdə təkrar olmayacaq»

Sübut: əvvəlki PPP tarixçəsində residiv təxminən 30–40% (profilaktikasız 44%-ə qədər); profilaktik plan vacibdir.

Mif 5: «Anti-NMDA-R ensefaliti nadirdir, axtarış tələb etmir»

Sübut: gənc qadında atipik psixoz + hərəki simptomlar + tutmalar Anti-NMDA-R ensefalitinin klassik təzahürüdür; antikor müayinəsi həyati əhəmiyyət daşıyır.
