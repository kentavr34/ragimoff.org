# RAGIMOFF /67 — прототип главной по новой дизайн-системе

Изолированная папка. Не связана с текущими страницами сайта: ничего не перезаписывает.
Опубликовано для проверки: `https://ragimoff.org/67/`

## Структура

```
67/
├── index.html          редирект на az/
├── az|ru|en/index.html сгенерированные страницы
├── assets/css/
│   ├── tokens.css      значения: цвет, шрифт, шкала, отступы, темы
│   ├── base.css        reset, типографика, prose, сетка
│   ├── components.css  кнопки, карточки, формы, видео, мифы
│   └── patterns.css    шапка, hero, секции, футер
├── assets/js/main.js   тема, меню, reveal, счётчики, ленивое видео
└── _build/build.py     генератор: TEXTS + DATA → HTML
```

## Правка

1. Тексты — в `_build/build.py`, словарь `TEXTS` (az/ru/en).
2. Цены и программы — `PROGRAMS`, `PROGRAMS_RU`, `PROGRAMS_EN`.
3. Стиль — только `assets/css/tokens.css` и компоненты.
4. Пересборка:

```bash
cd 67/_build && python build.py
```

## Принципы

- Один шаблон на страницу, тексты отдельно.
- Семантические токены: тема меняется переопределением `--bg`, `--text`, `--accent`.
- `prose` — единое правило для свободного текста.
- Никаких inline-стилей, кроме единичных служебных.
- Мобильная версия: 390 px, без горизонтального переполнения.
