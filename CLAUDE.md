## Устройство
- Сайт — один набор: тексты в `data/` и `assets/js/content.js`, показ в `assets/js/`, стили в одном файле `assets/css/site.css`, язык меняется без перезагрузки (AZ/RU/EN), темы night/paper/sepia.
- Библиотека книг: `books/<книга>/book.json` (паспорт) и `books/<книга>/<язык>/NNN.html` (главы); одна читалка `read.html?b=<книга>`.
- Прежний сайт целиком лежит в `D:\Projects\Ragimoff\old_versions\2026-11-12_site_before_v11\` (на GitHub — метка `site-before-v11-20261112` и ветка `archive/site-2026-11-12`). Оттуда сборщики только читают; менять там ничего нельзя.
- Оставлено от прежнего сайта в корне, потому что на это завязана работа: `payment/` (страницы возврата оплаты), `test/aile.html` и `test/quiz.*` (тест), `books/index.html`, `books/ru/`, `books/en/`, `books/books.js`, `books/books.css`, `books/order-form.js`, `books/covers/`, `_lang-switch.js` (страница заказа книг и корзина — временно, до переноса заказа в новую систему), `app/`, значки, `CNAME`.
- `404.html` переводит прежние адреса на новые страницы.
- Поиск, ИИ и превью ссылок (слово Кенана 13.11.2026): у каждой страницы и главы книги есть постоянный адрес на каждом языке — `/az/…`, `/ru/…`, `/en/…` (снимок с готовым текстом, title, description, canonical, hreflang, Open Graph, schema.org). Собирает `_tools/build_static.py` (нужен сервер 8812); он же пишет `sitemap.xml`, `robots.txt`, `llms.txt`, `assets/js/seo-map.js` и AZ-превью в шаблонах корня. Ссылки сайта на эти адреса переводит `assets/js/seo.js`. Язык по умолчанию — AZ (иначе язык браузера). После любой правки текста страниц, каталога или книг — перезапустить `build_static.py` (≈5 мин). Боты ИИ не выполняют JavaScript — текст для них только в снимках.
- Галереи дипломов и сертификатов: без повторов (страж `_tools/gallery_check.py`; разные документы одного шаблона — в `_tools/gallery_ok.json`); имена студентов на сертификатах не закрашивать (согласие студентов, проверка по QR-коду — слово Кенана 13.11.2026).
- Магазин (shop.html, book.html): ОДНА карточка для всех книг — обложка, название, автор, «год издания · страницы B5», цена, «Читать бесплатно» и «В корзину» (слово Кенана 13.11.2026). Год: у книг Кенана — год издания, у Фрейда — ГОДЫ НАПИСАНИЯ (не 2026); Фрейд — по хронологии от ранних к поздним, сборники писем и посмертных работ — в конце (`WRITTEN`/`COLL` в `shop_facts.py`). Сведения не пишутся вручную: их ставит `_tools/shop_facts.py` (страницы — по печатным PDF из Print проекта; отчёт — `_tools/shop_facts.json`). Порядок сборки каталога: `build_shop.py` → `merge_books.py` → `shop_facts.py`. После нового выпуска книги в печать — перезапустить `shop_facts.py`. Новая книга в каталоге без строки в `SRC` этого скрипта — ошибка (скрипт остановится).

- Карточки (книги, тренинги, услуги — любые в ряд): меняется только длина названия, все остальные поля — сведения, страницы, цена, кнопки — стоят на одной высоте во всех карточках ряда (слово Кенана 13.11.2026, обязательное требование). Сетки — подсеткой (`subgrid`) в site.css, ленты — `assets/js/align.js`. Страж — `pages_check.py` («поля карточек ряда на разной высоте»).

- Названия болезней (слово Кенана 13.11.2026, обязательное): в названиях книг, оглавлениях и текстах — только принятая AZ-номенклатура; «детский» в диагнозе = «uşaq», не «infantil» (Uşaq serebral iflici; infantil — только термин: infantil seksuallıq, infantilizm); один диагноз — одна форма (sarışan hallar nevrozu, nevropsixoz). Слово Кенана 14.11.2026: обсессия = навязчивость = «sarışan» (XBT-10 AZ F42.0, протокол Минздрава 2021), «məcburiyyət» — вынужденность (в неврологии «məcburi vəziyyət/hərəkət» = вынужденная поза, насильственные движения — остаётся); расстройство — «pozuntu», не «pozğunluq»; тревога — «təşviş»; «batil inanc» не чаще раза в абзаце (повтор — «xurafat»); турцизмы — по списку TURK в term_fix.py. ПРОВЕРКА ТЕРМИНА (слово Кенана 14.11.2026, обязательно): не из своего словаря — Google Translate в обе стороны + толковый словарь obastan.com + официальные AZ-тексты (XBT-10 AZ, протоколы МЗ isim.az, статьи вузов АР); «турцизм» — только если слова нет в AZ-словаре и источниках. «kimlik» (идентичность, «milli kimlik»), «üzgün» (изнурённый), «sinirli», «önəm», «bilgi» — азербайджанские. 6B64 = «Dissosiativ identiklik pozuntusu (DİP)» (ПОСЛЕДНЕЕ слово Кенана 14.11.2026; вариант «identifikasiya» отменён); «şəxsiyyət pozuntusu» — только расстройства личности 6D10/6D11 (с типом: sərhəd, dissosial…). Не путать. «etik pozğunluq» (испорченность) — верно. Правила и склонение — `_tools/term_fix.py` (его вызывают все сборщики каталога и библиотеки); новый термин — сначала `python D:/Projects/_MEMORY/tools/term.py <слово>`, затем правило сюда. Перечень и сверка — `_agent/docs/ДИАГНОЗЫ_AZ_ПЕРЕЧЕНЬ.md`. Сверка всех книг по базе истины, по этапам (названия → главы → тексты): `python _tools/term_audit.py titles|toc|text` (`refresh` — обновить выгрузку базы). ## Жёсткие правила
- В git добавлять файлы только по явному списку путей, никогда `git add .` / `-a`. Личные документы `_agent/docs/…`, `_agent/kpt/`, `_agent/server/`, `_agent/shots/` не публикуются.
- Сервер оплаты и заявок (`api.ragimoff.org`) — боевой: менять только по слову владельца; платёж не завершать; пробных заявок на сервер не слать (form_check.py подменяет отправку).
- Ничего не удалять (сначала копия); ключи и пароли не печатать; платные вызовы — после цены и «да» владельца.
- Согласованный вид закреплён замком (`_agent/lock/layout.json`); намеренное изменение принимается командой `pages_check.py accept`.
- Скрипты с кавычками и обратной чертой писать инструментом Write: heredoc в этой оболочке портит текст.
