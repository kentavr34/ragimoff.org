## Ошибки, найденные и исправленные

1. **Слои компонентов не подключались вообще.** Пути к CSS были `../design/`,
   но `design/` лежит рядом с `index.html` внутри `test/69/`. Браузер уходил в
   `test/design` → 404 → сервер отдавал HTML-заглушку вместо CSS. Файлы
   «подключались», правил в них было **ноль**, страница рисовалась без стилей:
   сетки не работали, обложки были во всю ширину, карточки ломались.
   → **Урок: проверять `cssRules.length` в каждом слое, а не факт загрузки.**

2. **Карточка специалиста высотой 53 px.** Абсолютное позиционирование текста
   не задаёт высоту блока, а фотографии были разного размера (335×600 и 576×1024).
   → Пропорция кадра на самой карточке.

3. **Текст не читался поверх фотографии** — затемнение начиналось с 42% и было
   коротким, лица уходили под нижний край.
   → Затемнение с 38% до 95% плюс `object-position: 50% 22%`.

4. **Ряды карточек шли ступенькой** (95 против 128 при одинаковом тексте).
   Причина оказалась не в числах, а в раскладке: `auto-fit` даёт разную ШИРИНУ
   карточек в неполном ряду — отсюда и разная высота.
   → Фиксированное число колонок плюс `height: 100%` на карточке.
   Правило одно на все ширины, числа подбирать больше не нужно.

5. **Кнопка шапки уходила за край** на 390 px.
   → На узком экране в шапке остаётся только переключатель языка.

6. **Ссылки на мифы были битыми** (`../klinik-psixiatriya/` вместо
   `../../klinik-psixiatriya/`) — из `test/69` нужно два уровня вверх.

7. **Canvas молча подставляет запасной шрифт** — проверка азербайджанских знаков
   без `document.fonts.ready` давала ложное «всё есть» даже для шрифта без
   единого знака. Заметил только потому, что результат противоречил прошлому
   замеру через fontTools.

**Я создал отдельные HTML-страницы — а это ровно та модель, от которой владелец
хочет уйти.** Три страницы = три HTML. Дальше их будет 160.

В `test/69/README.md` записан правильный путь: **SSG** — разметка одна, текст в
данных, сборка выдаёт языковые версии. Разметка главной, обучения и консультаций
уже написана и работает — её нужно перевести в шаблон, а текст вынести в
`templates/data/<язык>.json`. Тогда азербайджанская и английская версии появятся
без ручного переписывания, а 160 страниц превратятся в 3 шаблона.
