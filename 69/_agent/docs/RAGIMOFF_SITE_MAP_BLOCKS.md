## 6. Что важно учесть при аудите и правках

1. **Меню ведёт на якоря главной** (`#programs`, `#services`). С внутренних страниц переход по якорю не всегда приводит к нужному блоку — проверить.
2. **Книги — отдельный магазин** (`/books/`), не часть `/az|ru|en`. Стили и шапка могут отличаться.
3. **3 языка сайта, 4 языка книги** — не путать при правках.
4. **Повторяемые блоки** (`cta-band`, `stats-strip`, `badge`, карточки) должны управляться из одного места — иначе правки расползаются по страницам (жалоба Кенана 09.11).
5. **Порядок правки:** `build.py` → `verify.py` → `publish_live.py` → `git status | grep '^ D'` → commit/push только по слову Кенана.
6. **Старый сайт** — бэкап: тег `live-backup-2026-11-09`, ветка `archive/live-2026-11-09`, `_backups/site-live-2026-11-09.zip`.
