# ЧАСТЬ 4. ПУТЬ КЛИЕНТА — ГЛАВНОЕ

Кенан, дословно: *«Главная страница должна быть полноценной, отражающей главные элементы,

на дополнительные ресурсы. **Во всех блоках на главной странице должна быть отсылка.**»*

## Принцип

Главная = **посадочная страница**. Каждый блок показывает главное и **отдаёт** человека
на подробную страницу. Главная не перегружается деталями.

**Формула каждого блока:** главное + доказательство + **ссылка на подробности** + действие.

## Три маршрута клиента

### Маршрут 1 — специалист
Главная → блок специалистов (кратко) → **страница специалиста** (полная история,
документы) → возврат на главную.

Кенан: *«В блоке о специалистах краткая информация и кнопка с отсылкой "подробнее
об этом специалисте" на страницу именно этого специалиста... потом возвращается на главную.
Блок специалист уже закрыт.»*

### Маршрут 2 — консультация (пример: депрессия)
Главная → блок консультаций → видит тему «депрессия» кратко → **страница книги
«Вирус вины»** (рекомендация для столкнувшихся) → восхищение → **страница консультации
по депрессии** → истории пациентов, отзывы → **форма записи**.

Кенан, дословно: *«Меня это цепляет. Я хочу перейти на страницу книги "Вирус вины".
Перехожу и читаю её. Восхищаюсь этим человеком... И я уже хочу к нему на консультацию
записаться. Но я всё равно прохожу на страницу консультации, именно страницу депрессии,

Главная → блок обучения → программа (например, практикум по психотерапии) →
**страница программы** → галерея доказательств (сертификат, диплом международного образца,

Кенан: *«Эта галерея как доказательство. Можно даже фотография со студентами есть.

### Ключевое требование
Кенан, дословно: *«Такой же путь клиента по разным услугам у нас должен быть расписан,

**Каждая услуга — свой документированный маршрут от главной до регистрации.**

5. **Telegram — последним, после блога.**

Ни один блок не пытается рассказать всё сам — иначе получается «куча всего сразу»,

# ЧАСТЬ 9. ПРОВЕРЕНО НА ФАКТАХ (10.11.2026)

Прежде чем принять блок просвещения за реальный, я проверил книгу. Результат — блок
**осуществим технически, прямо сейчас**, без доработки книги.

## 9.1 Раздел «Мифы» есть в каждой главе

**104 главы** книги «Клиническая психиатрия» содержат раздел мифов. В каждой:
10–12 мифов с разбором.

Пример (глава об ОКП, AZ):
```
Mif 1: «OKP — sadəcə təmizlik və səliqə ilə əlaqədar şəxsiyyət xüsusiyyətidir»
Mif 2: «Pasiyent iradi olaraq obsessiyaları „dayandıra bilər“»
Mif 4: «ERP travma yaradır, çünki pasiyenti qorxulu situasiyada saxlayır»
Mif 5: «PANDAS OKP-nin əsas səbəbidir, hamı antibiotik almalıdır»
```

Это ровно то, что нужно: миф сформулирован **словами пациента**, и разбор попадает
в ложное убеждение, мешающее лечиться. Не «это неправда», а «вот почему это опасно».

## 9.2 Якоря существуют и совпадают между языками

У каждого раздела мифов есть `id` в формате `<код>-10-mifler`:

| Глава | Якорь (одинаковый во всех языках) |
|---|---|
| Тревожные расстройства | `6b00-10-mifler` |
| ОКП | `6b20-10-mifler` |
| Депрессивные | `6b01-10-mifler` |
| Паническое расстройство | `6b02-10-mifler` |
| … | всего 104 главы с мифами |

**Критически важно:** якорь `6b20-10-mifler` **одинаков** в AZ, RU, EN и TR.
Проверено: `id="6b20-10-mifler"` присутствует в каждой языковой версии.

Значит, ссылка строится предсказуемо и по языку страницы:

```
AZ → /klinik-psixiatriya/6B20.html#6b20-10-mifler
RU → /klinik-psixiatriya/ru/6B20.html#6b20-10-mifler
EN → /klinik-psixiatriya/en/6B20.html#6b20-10-mifler
TR → /klinik-psixiatriya/tr/6B20.html#6b20-10-mifler
```

Меняется **только путь** (папка языка), якорь остаётся один и тот же.
Это выполняет требование Кенана дословно: «именно на том языке, именно на тот раздел».

## 9.5 Что это меняет

Раньше блок просвещения выглядел как то, что «надо ещё сделать» — то есть требовал бы
написания раздела в книге. **Это не так: 104 главы уже написаны, с якорями,
на четырёх языках.**

Значит блок просвещения на главной — это **сборка уже существующего материала**:
берём 4 мифа из 4 глав и ставим ссылки. Не новый контент, а маршрутизация.

## 9.5 Масштаб книги (для понимания объёма)

- 104 главы с разделом мифов
- 820 страниц печати B5

Это подтверждает формулировку для блока книг: **не «384 страницы», а 820 (B5)**.
