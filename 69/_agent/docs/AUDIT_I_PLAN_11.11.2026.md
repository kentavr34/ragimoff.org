# ЧАСТЬ 3. ЧТО ДАЮТ НОВЫЕ ИНСТРУМЕНТЫ ПО БЛОКАМ

Ниже — конкретно, с прогнозом. Без общих слов.

## 3.1. Свои кадры героя через Blender (главная находка)

**Что было:** 90 кадров с прода — девушка ходит и нажимает кнопку. Владелец сам
сказал: половина кадров размыта, лишние шаги надо убрать, лицо упирается в меню.

**Что можно:** Blender 5.3 в headless-режиме рендерит любое число кадров
из моей же сцены. Значит кадры можно сделать **под наш стиль**: свои материалы,
свой свет, своя палитра, точная камера.

**Прогноз применения:** ⭐⭐⭐⭐⭐ **Высокий.** Это убирает главный недостаток
героя и даёт то, чего нет у конкурентов — своё видео, а не сток.

**Что нужно решить:** сюжет. Варианты:
- (а) абстрактный кинетический объект (стекло, частицы, свет) — безопасно, дорого
  выглядит, не требует актёра;
- (б) сцена сессии — сложнее, риск «дешёвой реконструкции»;
- (в) метаморфоза: хаос частиц → упорядоченная структура (метафора терапии).

Рекомендую **(в)**: она говорит о сути работы без слов и не требует человека.

## 3.2. Three.js в герое

**Прогноз:** ⭐⭐⭐⭐ высокий, но **с ограничением по весу**: сборка 2.1 МБ.
Для прода — собрать только нужные модули (цель ≤ 180 КБ).

**Применение:** стекло и частицы поверх видео-скраба, реакция на движение мыши.
Осторожно: не перекрывать лицо и не мешать тексту.

## 3.3. matter.js — физика

**Прогноз:** ⭐⭐⭐⭐ высокий, но **точечно**.

**Где реально сильно:** блок мифов. Миф — это «установка», которая держит человека.
Разрушить её физически — убедительная метафора: строишь из кубиков ложное убеждение,
оно рассыпается. Или: неверные убеждения падают и разбиваются при прокрутке.

**Где НЕ применять:** в герое (отвлекает), в книгах (лишнее), в формах (мешает вводу).

## 3.4. Blender для 3D-объектов блоков

**Прогноз:** ⭐⭐⭐⭐. Обложки книг, объёмный знак книги, вращающийся объект
для блока обучения. Даёт объём там, где сейчас плоскость.

## 3.5. ffmpeg + librosa — видео и звук

**Прогноз:** ⭐⭐⭐. Раскадровка, сжатие, нарезка кадров из готового видео.
librosa — синхронизация движения с ритмом (если будет музыка).
**Звук:** деликатный, по умолчанию выключен, включается кнопкой.

## 3.6. Озвучка (Gemini TTS / ElevenLabs)

**Прогноз:** ⭐⭐⭐⭐⭐ **очень высокий** — аудиоверсии книг и озвучка приветствия.

## Логика, по которой строю

Человек не читает — он **сканирует и уходит**. Задача: **не дать уйти,
дав доказательство раньше, чем он успеет усомниться.**

**Главный сдвиг против прежнего:** доказательство **вверх**, а не вниз.
Раньше: сначала услуги, потом доказательства. Человек уходил до доказательств.
Теперь: **сначала то, что невозможно оспорить** — учебник на 4 языках,
переводы Фрейда, диплом в реестре.

# ЧАСТЬ 5. ТРИ ЯЗЫКА

**Требование владельца:** один файл разметки, текст — из отдельного файла
данных, при выборе языка подставляется текст. Число страниц уменьшается втрое.

## 5.1. Устройство

```
test/69/
├── templates/
│   ├── page.html            ← РАЗМЕТКА. Одна на все языки
│   └── data/
│       ├── az.json          ← тексты азербайджанского
│       ├── ru.json          ← русские
│       └── en.json          ← английские
└── build.py                 ← сборка: разметка + язык → страница
```

**Внутри шаблона:** вместо текста — ключ.
```html
<h1 class="pagehead__title">{{block.specialists.title}}</h1>
```

**Внутри данных:**
```json
{ "block": { "specialists": { "title": "Два специалиста, одна школа" } } }
```

## 5.2. Правила

1. **Ключи одинаковы во всех языках.** Сборка падает, если языка не хватает
   хоть одного ключа — это и есть проверка полноты перевода.
2. **Разметка языконезависима.** Если для языка нужна другая длина строки —
   меняется стиль по атрибуту `[lang]`, а не разметка.
3. **Язык определяется один раз:** по геолокации на корневом `index.html`
   (Азербайджан → азербайджанский), дальше выбор владельца сохраняется.
4. **Адреса:** `/az/`, `/ru/`, `/en/` + `hreflang` для поисковых систем.
5. **Числа и цены — из данных, а не из разметки:** 100 AZN / 5000 ₽ / 50 $.

## 5.3. Что это даёт

- правка текста — в одном файле, появляется сразу во всех языках
- добавить четвёртый язык (турецкий, для книги он уже есть) — один файл данных
- переводчик может работать **не глядя в разметку**

# ЧАСТЬ 8. ПЛАН РАБОТ ПО ШАГАМ

## Шаг 1. Разметка и содержание героя (первым делом)
1.1. Название — «Школа психологии, доктор Рагимов».
1.2. Заголовок ≤2 строк, подзаголовок ≤2 строк. Замером проверить.
1.3. Шапка: воздух между логотипом и меню, кнопка не упирается в край.
1.4. Кадр: текст не на лице. Пересчитать положение и кегль.

## Шаг 2. Своё видео героя
2.1. Сцена в Blender: метаморфоза хаос → структура.
2.2. Рендер 60–90 кадров, оптимизация в WebP.
2.3. Скраб по прокрутке, кадры чёткие.

## Шаг 3. Движение и темы
3.1. Анимация видна с первой секунды, не только по скроллу.
3.2. Затемнение — минимальное, плавное, только при переходе.
3.3. Переключатель трёх тем в шапке + сохранение выбора.

## Шаг 4. Система языков
4.1. Разметка → шаблон. Текст → три файла JSON.
4.2. Сборка `build.py` + проверка полноты перевода.
4.3. Определение языка по геолокации.

## Шаг 5. Блоки-доказательства
5.1. Новый блок «доказательство масштаба» после специалистов.
5.2. Мифы: физика разрушения установок.
5.3. Книги: выразительное название, читалка с темой сепия.

## Шаг 6. Формы
6.1. Консультация: имя, фамилия, телефон. Без документов.
6.2. Обучение: + удостоверение обязательно, диплом нет.
6.3. Оплата → согласование времени.

## Шаг 7. Аудит по каждому пункту
7.1. Пройти свод требований заново.
7.2. Замером проверить каждый пункт.
7.3. Составить список несоответствий и закрыть их.
7.4. **Затем** залить и показать.

# ЧАСТЬ 9. ЧТО НУЖНО ОТ ВЛАДЕЛЬЦА

1. **Ключи Gemini TTS и ElevenLabs** — для озвучки. Положить в файл,
   в чат не присылать.
2. **Сюжет видео героя** — какой из трёх вариантов (3.1) или свой.
3. **Решение по рукописному шрифту** — искать новый или сгенерировать.
4. **Подтверждение порядка блоков** — особенно двух новых (доказательство
   масштаба и мифы вперёд).
